# Section library

Every section design (a "look") the site has had, with the content it showed. 171 looks: 141 live on a page, 30 retired. Each one still renders with its motion in the [Section library](../sections.html); this file is generated by `python tools/specimens.py catalog` from `design-system/specimens/` (do not edit it by hand).

**Swap a look.** A look renders one block type (the shape of data it shows). For a block of the same type, set its `"look"` to another look of that type and rebuild; check that the block has the fields the look reads (Fields below) and an item count inside the range it has held. For a look of another type, restructure the content to that look's fields and type (copy the specimen's block in `design-system/specimens/<look>.json` as the template). Before inventing a new look, run `python tools/specimens.py fit <type>`.

**Never delete a look.** A look no page uses is retired: its renderer, component folder, motion and specimens stay, built into the library bundles (not the site's), so it can be reused by setting `look` on a block again. After page edits, run `python tools/specimens.py snapshot` before shipping so every content version is kept.
