Placeholder marks a fact only Aquemi can supply (a capacity, lead time, certificate, location, case-study figure) so an invented number never ships.

- Write it in square brackets: `<span class="aq-ph">[lead time in weeks]</span>`. The website wraps any `[bracketed text]` in page copy automatically.
- It shows on an amber `caution-tint` ground in mono type. Add `is-clean` to an ancestor (the site's "Highlight placeholders" switch does this) to see the page as a reader would.
- Say what is needed and its unit: "[capacity, L/h]", not "[TBD]".
- Before launch, every placeholder is either replaced with a confirmed fact or the sentence is removed. Agents must never fill one with a guessed value.
- Pass 12 (S5): a chip that wraps keeps its tint, padding and corners on every line (`box-decoration-break: clone`), with a hair of block padding, so the highlight never splits into a ragged half. On phones a chip stays between 13 px (`--aq-chip-phone`, the size in 15 px body) and 16 px, whatever the text around it: a placeholder inside a display-size figure, a headline or a hero callout never becomes four lines of 40 px mono. The layout around a placeholder must hold the real value too: check a section with the "Highlight placeholders" switch off (`is-clean`), where the chip takes the surrounding type.
- Pass 12 (S6, the tap-target contract in `base.css`): a plain link (no class) in a sentence or note inside a section gets an automatic inline hit padding to 44 px (`--aq-hit`), with no counter-margin, so no line moves. That padding is for inline links only. A look that sets such a link to flex, inline-flex or inline-block, or pads it itself, adds the link's parent to the hit-padding reset in `base.css` or gives the link a class (plus `.aq-hit` where it is under 44 px), so the look keeps its own sizing.
- Pass 12 round C: inside a hero headline (`.aq-hero h1`) the chip is set at 0.62 em with line-height 1.5 and `box-decoration-break: clone` (`Placeholder/style.css`), so a headline placeholder (contact-service, `[makes and equipment types serviced]`) reads as a tinted note in the headline, never as display-size mono; the clean view takes the headline's own type. At 600 px and under (verify V6) it is 0.45 em with line-height 1.35 (about 18 px), so it no longer fills three display lines.
