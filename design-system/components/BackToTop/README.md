BackToTop is a quiet floating button that returns the reader to the top of a long page once they are well down it.

- Markup: `<button class="aq-back-to-top" type="button"><span class="aq-back-to-top__arrow" aria-hidden="true">↑</span><span class="aq-back-to-top__label">Back to top</span></button>`, placed once per page after the footer. On the site, `wBackToTop()` in `assets/src/parts/BackToTop.js` writes it and `wPage` adds it to every page.
- Behaviour: hidden and out of the tab order within the first screen. **One screen down it fades in and stays while the reader scrolls on, in either direction**, so the top is always one press away (200 ms, `cubic-bezier(0.2, 0, 0, 1)`, `is-shown`). On phones and tablets (the 44 px square) it steps aside while the footer is partly in view, so it never sits on the footer's disclosure chevrons, and returns at the page end, where the footer keeps 56 px clear under its legal line for it. It stays while it has keyboard focus. Pressing it scrolls to the top (smoothly, or instantly under reduced motion), stays hidden for the trip up, and moves focus to the logo link, so keyboard and screen-reader users start from the top as well. One scroll listener, one update per frame.
- Look: a control, so `surface-raised`, a 1 px `line-strong` rule turning `ink` on hover, `radius-sm`, 44 px tall, the `label` type (Geist 14/20, 500) in sentence case, the arrow in `flow`. It floats over content, so it takes `shadow-overlay`, the brand book's one shadow. Focus is the standard 2 px `focus` ring.
- Position: fixed `space-8` from the bottom right on desktop. Phones: the arrow alone in a 44 × 44 px square (`--aq-hit`) on the solid `surface` ground, `space-4` from the edge, inside a 56 px bottom safe area (`space-4` plus `env(safe-area-inset-bottom)`, clear of a home bar); the label stays for screen readers.
- One per page. Don't add other floating controls beside it, and don't use it on short pages where the top is a scroll away; the threshold already keeps it hidden there.
