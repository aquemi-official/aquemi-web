CostSkid reads running costs off the system itself: one Purified Water skid in IsoKit line art beside the title, a numbered leader from each part a cost row belongs to, and the running-cost table under it led by the same numbers.

Look `cost-skid` (`assets/src/blocks/look-cost-skid.js`) on a `spec` block. Used on svc-service, "What it costs to run". Concept: research/pass9b/concepts/svc-service.1.png (a skid with numbered leaders over the running-cost table).

- Markup: `section.aq-cost-skid-sec` > `div.aq-cost-skid` > `__top` (the section head, `div.aq-iso-figure.__fig` > `svg.aq-iso.__svg` (the skid; leaders `g.aq-iso__leader[data-r]`) + `span.aq-iso-figure__label.__pin[data-r]` numbers, aria-hidden), then `table.__table`: `thead` (number column with `__sr` text, item, value, set by), `tr.__row[data-r][data-parts][tabindex=0]` > `td.__n`, `th.__p` (a link when the row has one), `td.__v`, `td.__m[id]` (phone labels `__k`), `td.__why > button.__wb[aria-expanded][aria-controls]` (phones only).
- Fields: `h`, `intro`, `cols` [item, interval or amount, set by], `rows [{p, v, m, link, part}]` (`fold`, `fold_noun` are no longer read: every row shows). `part`: the skid stage(s) the row belongs to, space-separated: `panel`, `gen` (RO rack and EDI), `pre` (carbon vessel), `soft` (softener and brine tank), `uv`, `pump`, `drain` (the reject line off the frame edge). The number sits on the first stage named; a row without a part has no number on the drawing.
- Scene (fixed, one PW skid, `csScene()`): base frame, softener, carbon, RO rack, EDI stack, loop pump, UV unit, control panel; the reject line drops to the floor with a flow arrow. Leaders are short, up from each part's top to its number; numbers that would meet are moved apart.
- Tokens: IsoKit default ground (follows the theme); leaders `ink-muted`; pins `surface` with a `line-strong` edge, `flow` when lit; table hairlines; a lit row `flow-tint`.
- Phones (pass 12, audit S7): every row shows (the numbers on the drawing point at them; no fold). Each row is two
  compact lines: number and item (16 px), then the value (14 px) with a 44 px button (13 px mono) at the right named by the third
  column ("Set by", or "Note" on cmp-documentation) that opens that column's text under the row (`aria-expanded`;
  focusing or tapping the row also lights its parts). A row title that links has a 44 px hit box. Used on
  svc-service (running cost), ind-process (from exchange DI) and cmp-documentation (site safety, 7 rows).

Motion: the skid draws itself with IsoKit's choreography (parts back to front, pipes and leaders, the water runs the train once), then each cost row is wired in: its number strikes at the part (scale 1.6 to 1, 0.35 s), the row prints and its parts light for a moment. One timeline, under 5 s. Hover or focus on a row lights its parts, leader and number (repeats).

Round C: values set in sans 15/22; only a `[bracketed]` placeholder (its `.aq-ph` chip) is mono, so a written value ("None: RO and EDI make the water on site", "Certificate of insurance ...") no longer switches the column into mono. The "Site safety" use (`section#safety`, cmp-documentation) puts the drawing from grid column 6 (5fr / 7fr at 861 px and up), so the long heading never runs into it, with `space-8` under the drawing above the table's header rule (861 px and up only); svc-service and ind-process keep 4fr / 8fr. The pretreatment vessels are IsoKit parts (owner: IsoKit).
